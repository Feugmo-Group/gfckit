# gfckit datasets — data dictionary

Most data here is generated by the `gfckit` package (pure-JAX identification
core; PyBaMM used only as an independent physics-based simulator) and has
**known ground truth**, which is the point: identifiability can only be *proven*
where truth is known.

Two directories are exceptions and carry no ground truth — `real/` (measured
cells from published datasets) and `fracmd/` (LAMMPS molecular dynamics). They
support the claims that do not need truth: that an effective order is
recoverable from real curves, and that no published cell spans the observation
window a spectrum would require.

```
gfckit/data/
├── DATA.md                     ← this file
├── synthetic/                  ← controlled fractional / reduced-physics curves
│   ├── benchmark.csv
│   └── battery_cohort.csv
├── pybamm/                     ← independent physics-based aging ensemble
│   ├── summary.csv
│   └── <cell_id>.npz           ← one file per simulated cell
├── aged_eis/                   ← per-mechanism aged impedance (JES paper)
├── pybamm_targeted/            ← targeted mechanism sweeps (JES paper)
├── real/                       ← measured cells; NOT tracked in git (814 MB)
│   ├── oxford/                 ← Oxford Battery Degradation Dataset 1
│   └── zhang2020/              ← Zhang et al. 2020, Zenodo 3633835
└── fracmd/                     ← reduced MD output; trajectories stay on Nibi
    └── <comp>/T<K>/r<n>/msd_tier{A,B,C}.dat
```

**What the public repository ships.** Only `pybamm_targeted/` and `aged_eis/`
(under 1 MB together), which are all the battery paper needs. The other
directories are too large for git or are not ours to redistribute.

**`real/` is not redistributed**: it is public, re-downloadable, and not our
data. `reproduce/battery/fetch_real_data.sh` downloads both datasets (Zhang et
al. 2020, Zenodo 3633835; Oxford Battery Degradation Dataset 1,
doi:10.5287/bodleian:KO2kdmYGg) and checks their checksums. Run it before any
`examples/real_*.py` script.

**`fracmd/` holds only the reduced MSD tiers.** Trajectories (~1.3 GB per run)
stay in `~/scratch/fracMD/runs/` on Nibi. Tier A samples every 1 fs to 10 ps, B
every 100 fs to 1 ns, C every 10 ps to 20 ns, so one run spans ~7.3 decades once
stitched by `examples/fracmd_msd.py`. Column 0 is the timestep, equal to
femtoseconds (the MD timestep is 1.0 fs); column 4 is the total Li MSD in Å².

Provenance (which script writes or consumes what):
| Dataset | Generator script | Module(s) |
|---|---|---|
| `synthetic/benchmark.csv` | `examples/generate_benchmark.py` | `benchmark.py`, `complex.py`, `fick.py`, `physics.py` |
| `synthetic/battery_cohort.csv` | `examples/generate_benchmark.py` | `realistic.py` |
| `pybamm/*` | `examples/pybamm_ensemble.py` | `pybamm_gen.py` (PyBaMM) |
| `aged_eis/*` | `examples/aged_eis_run.py` | `aged_eis.py`, `eis_gen.py` (PyBaMM) |
| `real/*` | *downloaded, not generated* | read by `real_data.py` |
| `fracmd/*` | LAMMPS on Nibi (`in.frac`) | read by `examples/fracmd_msd.py` |

## 1. `synthetic/benchmark.csv`

Seven labeled degradation curves in two families, each with a realistic sparse,
noisy measured signal and the clean ground-truth signal. Used to test
non-power-law **detection** and effective-order recovery.

**Long format**, one row per (dataset, time point). Columns:

| Column | Meaning | Units |
|---|---|---|
| `dataset` | curve name (see below) | — |
| `family` | `power-law` or `non-power-law` (ground-truth class) | — |
| `t` | time (dimensionless or model units) | — |
| `y_measured` | observable with sparse sampling + noise/drift/outliers | — |
| `y_clean` | noise-free ground-truth signal | — |
| `pl_alpha` | best single-power-law exponent fit to this curve | — |
| `pl_R2` | R² of that single-power-law fit | — |
| `slope_var` | variation of the local log–log slope (≈0 ⇒ power law) | — |

Datasets: **power-law family** — `powerlaw_alpha` (u=t^0.5), `fick_uptake`
(diffusion-limited √t), `sei_reduced` (mixed reaction–diffusion SEI);
**non-power-law family** — `multiterm` (distributed/multi-order), `variable_order`
(α(t) drifts), `knee_battery` (SEI + plating knee), `pdm_passivation` (Point
Defect Model, saturating).

Ground truth = the `family` label and the generative parameters (in
`benchmark.py`, `make_benchmark`).

## 2. `synthetic/battery_cohort.csv`

A realistic multi-temperature calendar-aging cohort from the **exact** reduced
SEI growth law `L(t)=D(√(1/k²+2t/D)−1/k)` (mixed reaction–diffusion), with
Arrhenius temperature dependence, cell-to-cell variability, sparse check-ups, and
a measurement model. Used for multi-condition identification demos.

**Long format**, one row per (cell, check-up day). Columns:

| Column | Meaning | Units |
|---|---|---|
| `temp_C` | aging temperature | °C |
| `cell` | cell index within a temperature group | — |
| `day` | check-up time | days |
| `capacity_pct` | **measured** capacity retention (noisy) | % |
| `capacity_true_pct` | noise-free capacity retention | % |
| `k` | ground-truth reaction rate constant (per cell) | model units |
| `D` | ground-truth diffusion constant (per cell) | model units |

Ground truth = per-cell `(k, D)` and the Arrhenius activation energies (in
`realistic.py`, `generate_battery_cohort`).

## 3. `pybamm/` — physics-based aging ensemble (mechanism-recovery study)

Generated with **PyBaMM** (SPMe electrochemical model, `OKane2022` parameters)
by cycling each cell for `n_cycles` (default **300**) under an accelerated
protocol. This is *independent* ground truth: PyBaMM does not use our fractional
kernels, so recovering mechanism from it is a genuine cross-model test.

**The scientific setup:** the **observable** is capacity fade (+ a voltage / dV-dQ
curve); the **hidden ground truth** is the capacity loss attributed to each
degradation mechanism. The question is which mechanisms are identifiable from the
observable, and under which conditions/observable sets.

### 3.1 Configurations (mechanism combinations)

12 configs (PyBaMM `BatteryModelOptions`); SEI is `solvent-diffusion limited`
unless noted:

| Config | Mechanisms enabled |
|---|---|
| `SEI_solvent` | SEI (solvent-diffusion) |
| `SEI_reaction` | SEI (reaction limited) |
| `SEI_ec` | SEI (ec-reaction limited) — fast fader |
| `SEI_plating_pr` | SEI + lithium plating (partially reversible) |
| `SEI_plating_irr` | SEI + lithium plating (irreversible) |
| `SEI_LAM_stress` | SEI + loss of active material (stress-driven) |
| `SEI_LAM_reaction` | SEI + LAM (reaction-driven) |
| `SEI_crack` | SEI + particle cracking + SEI-on-cracks |
| `SEI_plating_LAM` | SEI + plating + LAM |
| `full` | SEI + plating + cracking + SEI-on-cracks + LAM |
| `plating_heavy` | SEI (reaction) + plating (irreversible) |
| `LAM_current` | SEI + LAM (current-driven) |

### 3.2 Conditions (accelerated)

| Condition | Ambient T | Discharge | Charge | Purpose |
|---|---|---|---|---|
| `mild_25C` | 25 °C | 1C | 0.5C | baseline |
| `hot_45C` | 45 °C | 1C | 0.5C | accelerate SEI |
| `cold_10C_fast` | 10 °C | 1C | 1C | provoke lithium plating |

Cell id = `<config>__<condition>` (e.g. `SEI_plating_irr__cold_10C_fast`).
Up to 12 × 3 = 36 cells (some harsh combos may fail to converge and are logged).

### 3.3 `pybamm/summary.csv`

One row per cell (quick index / labels):

| Column | Meaning | Units |
|---|---|---|
| `cell_id` | `<config>__<condition>` | — |
| `config` | configuration name | — |
| `condition` | condition name | — |
| `n_cycles` | cycles completed | — |
| `retention_end` | end-of-life capacity retention | fraction |
| `dominant` | **ground-truth** dominant mechanism (`SEI`/`plating`/`cracks`/`LAM`) | — |
| `loss_SEI` | end capacity loss to negative SEI | A·h |
| `loss_plating` | end capacity loss to lithium plating | A·h |
| `loss_cracks` | end capacity loss to SEI-on-cracks | A·h |
| `LAM_neg_pct` | end loss of active material (neg. electrode) | % |
| `status` | `ok` or `FAIL:<ErrorType>` | — |

### 3.4 Per-cell `pybamm/<cell_id>.npz`

Full trajectories (load with `numpy.load(path, allow_pickle=True)`):

**Observables** (what an experimenter could measure):
| Key | Meaning | Shape / units |
|---|---|---|
| `cycle` | cycle number | (N,) |
| `capacity_Ah` | discharge capacity per cycle | (N,) A·h |
| `capacity_retention` | capacity / initial capacity | (N,) fraction |
| `dvdq_Q` | discharge-capacity axis of the **clean low-rate (C/20 RPT)** curve | (M,) A·h |
| `dvdq_V` | terminal voltage vs `dvdq_Q` | (M,) V |
| `dvdq` | dV/dQ (differential voltage, DVA) from the low-rate RPT | (M,) V/A·h |
| `vq_first_Q`,`vq_first_V` | raw discharge voltage curve at **begin-of-life** | cycler-like |
| `vq_mid_Q`,`vq_mid_V` | raw discharge voltage curve at **mid-life** | cycler-like |
| `vq_last_Q`,`vq_last_V` | raw discharge voltage curve at **end-of-life** | cycler-like |
| `vq_rpt_Q`,`vq_rpt_V` | low-rate (C/20) diagnostic discharge voltage curve | cycler-like |

The `vq_*` are the actual charge/discharge voltage–capacity curves a cycler
produces; `dV/dQ` (DVA) and `dQ/dV` (ICA) are computed from the low-rate RPT.

**Ground truth** (hidden mechanism decomposition, per cycle):
| Key | Meaning | Shape / units |
|---|---|---|
| `loss_SEI_Ah` | capacity loss to negative SEI | (N,) A·h |
| `loss_plating_Ah` | capacity loss to lithium plating | (N,) A·h |
| `loss_cracks_Ah` | capacity loss to SEI-on-cracks | (N,) A·h |
| `LAM_neg_pct` | loss of active material (neg. electrode) | (N,) % |
| `LLI_pct` | loss of lithium inventory | (N,) % |

**Metadata**: `config` (JSON dict of mechanisms), `condition` (JSON dict of
T/C-rates), `dominant` (str label).

### 3.5 How to load

```python
import numpy as np
d = np.load("gfckit/data/pybamm/SEI_plating_irr__cold_10C_fast.npz",
            allow_pickle=True)
obs_capacity = d["capacity_retention"]     # observable
truth_plating = d["loss_plating_Ah"]        # hidden ground truth
label = str(d["dominant"])                  # "plating"
```

### 3.6 Intended use

- **Mechanism recovery**: predict the active mechanism(s) / their fractions from
  observables only (`capacity_retention`, `dvdq_*`), scored against the ground
  truth. **Do not** train on the ground-truth loss arrays — those are the answer key.
- **Identifiability map**: compare recovery from *capacity only* vs *capacity +
  dV/dQ* vs (phase-2) *+ EIS*, and across the number of conditions — the expected
  result is that SEI-LLI and plating-LLI are degenerate from capacity alone and are
  separated by dV/dQ / low-temperature contrast.

## 4. `pybamm_targeted/` and `aged_eis/` — the battery paper's ensemble

`pybamm_targeted/` is the balanced 24-cell ensemble every number in the battery
paper comes from: 8 configurations x 3 conditions, 200 cycles each, then a C/20
reference discharge. Appendix B of the paper lists every setting;
`examples/pybamm_targeted.py` regenerates it. One `<config>__<condition>.npz`
per cell, plus `summary.csv` (one row per cell: end-of-life retention, dominant
mechanism, per-mechanism losses in A h).

Arrays in each `.npz`: `cycle`, `capacity_Ah`, `capacity_retention`; the ground
truth `loss_SEI_Ah`, `loss_plating_Ah`, `loss_cracks_Ah`, `LAM_neg_pct`,
`LLI_pct` per cycle; the reference-test curve `dvdq_Q`, `dvdq_V`, `dvdq`;
voltage-capacity curves of the first, middle and last cycle and the reference
test (`vq_*`); and `config`, `condition`, `dominant`.

`aged_eis/` holds the impedance of each of those 24 cells, solved on its
end-of-life internal state at 50% SOC (`examples/aged_eis_run.py`): `freqs`,
`Z_re`, `Z_im`, the aged state and the fitted features. `summary.csv` collects
`R_s`, `R_ct` and the aged state per cell.

`reproduce/battery/` runs every analysis on these two sets.
